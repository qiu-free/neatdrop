# NeatDrop 净匣

一个可以实际运行的本地文件整理 MVP：扫描目录、解析内容、生成可编辑建议、
审核建议、生成归档副本、在资料库分类查看、用离线知识图谱探索关系，并在 Windows
安全条件满足时撤回副本。

**安全模式：只生成副本，始终保留原件。不执行原位移动、源文件删除或永久删除。**
这不是释放磁盘空间的工具；副本与撤回区都仍然占用空间。

## 快速启动（Windows）

需要 Node.js 22.12+（建议当前 LTS）、Python 3.12.x；推荐安装 uv。
项目同时提供 Python `requirements.lock` 与前端 `package-lock.json`。

在项目目录的 PowerShell 运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

首次启动会创建独立 `.venv`、安装依赖、构建界面、创建人工样例，然后在
[http://127.0.0.1:8765](http://127.0.0.1:8765) 提供前端与 API。
不会自动改动任何待整理目录。终端按 Ctrl+C 停止服务。

安装完成后可跳过依赖检查和构建：

```powershell
.\scripts\start.ps1 -SkipInstall
```

如果系统禁止脚本执行，使用上述单次 `-ExecutionPolicy Bypass` 命令即可；
不需要修改整台电脑的全局执行策略。不要使用管理员权限运行。

## 第一次使用

1. 首次导览展示“选择 → 分析 → 复核 → 计划与复制 → 资料库 → 记录与撤回”完整流程，
   可跳过或重播。“进入教程演练”提供相同六阶段的内存演练：查看与勾选、一键审核、
   修改后重审、独立确认复制、预览副本和撤回。练习不读取真实目录、不联网、不创建文件。
2. “选择本地目录”，或粘贴完整路径扫描。扫描后不自动勾选；明确选择资料，
   批量选择仅作用可见项，单批最多 50 项、200 MiB。
3. 按“选择 → 分析 → 复核 → 结果”推进。默认离线，可取消并保留已完成建议；
   失败项单独重试。也可跳过分析，手动编辑名称、主分类与子分类。
4. 点击文件在右侧打开详情，复选框只表示加入批次。复核页核对列表中的分类与名称，
   可“一键审核已选项”，也可打开详情单独调整和确认。尚未分析且未手动编辑、
   或仍有分析错误的文件不能通过一键审核。修改或重新分析会使对应核对和旧计划失效。
5. 生成固定计划，核对原名称和目标路径，重新勾选确认后执行。结果页显示实际
   成功、失败、未执行数。断线后仅查询状态和记录，不自动再次发送复制请求。
6. 在“资料库”按分类筛选、搜索并预览当前目录生成的副本。副本在本机分类子目录中，
   不上传到网站服务器或云端。刷新或重启服务后，重新选择相同目录即可读取持久记录。
   缺失、被替换或没有本机可信凭据的副本不能预览；预览时会再次核对内容。
7. 在“操作记录”查看逐项结果。Windows 的“撤回归档副本”会将未改动副本
   移到同目录的 `.neatdrop/withdrawn/<事务ID>/`；原件不动，文件不删除。

## 离线知识图谱

归档后打开“知识图谱”，通过 Graphify 风格的圆形节点网络浏览分类与副本。
分类配色和分组数量来自已有归档记录；点击文件可打开可信预览，点击连线可查看
关系依据。“局部关系”用于聚焦一份文件及其直接关联资料。文件与关系列表提供
相同的键盘操作入口。

“分析关联”需要主动选择副本并同意在本机保存有限关键词、位置与图像指纹。
文本采用本机稀疏词项匹配，图片提供感知指纹相近候选；没有云端调用、CDN 或
运行时模型下载。自动候选始终标为待确认，不能自动认定引用、版本或主题事实。
相同 SHA-256 的连线只说明归档时内容相同，查看依据会重新核验当前副本。

可确认或忽略候选，也可人工添加相关、引用、配套说明或版本关系。本机索引支持
取消和清除；正常清除保留人工关系与文件。索引保存在安装目录
`.neatdrop-state/knowledge-graph/`，不保存全文或原始 OCR。单目录最近 1000 份副本，
画布最多 200 节点，局部视图最多 20 个邻居；列表保留全部返回的筛选结果。
撤回副本后，相应文件和关系不再展示。重新授权同一目录可恢复人工关系。

图谱形态参考 [Graphify](https://github.com/Graphify-Labs/graphify)，使用本项目的本机
关系提取与可信读取流程，随前端打包交付。合成验收结果和能力边界见
[v9 交付报告](docs/v9-delivery-2026-11-06.md)。

完整步骤、分类标准、模型设置和故障恢复见 [日常使用指南](docs/daily-use.md)，
应用内“使用说明”提供搜索、主题目录和本地配图。浏览器只保存显示密度、离线
优先偏好和教程进度，不恢复真实资料草稿。

工作台、资料库和帮助之间切换会在本次会话保留草稿、筛选和滚动位置，离开的页面
取消内容预览请求。页面与侧栏采用短过渡；系统启用“减少动态”时关闭非必要动画。
导览跳过与完成分别记录；旧版无法区分的已关闭状态迁移为“旧版已关闭”，不伪造完成记录。

人工样例仅创建在本项目 `demo-files/` 下，包含中文文本、合成截图和一个明确不支持
的伪 DOCX 测试文件。不会覆盖已存在的样例，也不会将其当成真实识别质量证据。

## 可选：配置真实模型

打开“模型设置”，选择百炼或自定义 Chat Completions 兼容服务，填写地址、
API Key、文本/视觉模型与单批请求限额。保存只做静态校验；“测试连接”需主动
确认可能计费，仅发送固定示例文本，成功不表示视觉能力已验证。

界面配置由当前 Windows 用户 DPAPI 加密，版本化、原子保存到
`.neatdrop-state/model-config/settings.json`，与撤回凭据分开。查询不返回密钥，
输入提交后清空，不写入浏览器存储。密钥与服务地址绑定，更换地址必须重新提供
密钥。解密失败显示未配置并保留原文件，不降级为明文。

仍可复制 `.env.example` 为 `.env`，填写后重启。环境变量优先，覆盖字段在界面
显示来源并锁定；环境密钥生效时服务地址同时锁定。

```dotenv
NEATDROP_API_KEY=你的服务商密钥
NEATDROP_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
NEATDROP_TEXT_MODEL=qwen-plus
NEATDROP_VISION_MODEL=qwen-vl-plus
NEATDROP_MAX_MODEL_REQUESTS=20
```

兼容 OpenAI Chat Completions JSON 输出协议的 Qwen 服务是候选配置。具体模型可用性、
权限、价格、视觉格式和服务商数据政策必须自行核对。**本项目没有附带密钥，不声称
已经验证真实模型识别质量。** 不要把密钥提交到版本控制或粘贴到聊天中。

选择云端模式后，每次仍须明确授权：只发送去除 EXIF 的 ≤1024px JPEG 缩略图，
或 ≤1500 字符的抽样文本；不发送原件、绝对路径、文件句柄和内容摘要。
不自动访问提取的链接，不自动执行文件内容中的指令。

云端每文件最多一次请求、串行执行、无自动重试、60 秒请求超时、默认每批最多
20 次请求。请求数限额不是货币预算；本版不计算模型费用，不承诺零留存。
取消只阻止后续请求，已发出的请求可能仍计费。

服务仅允许公网 HTTPS；每次连接校验所有 DNS 结果并固定到本次验证的公网地址，
保留原服务名 TLS 校验，禁用重定向和环境代理。云端任务启动时固定配置快照，
后续配置更新不改变已授权任务；新任务按服务地址及配置版本重新授权。

## 离线分类与图片模型

本地 OCR（RapidOCR PP-OCRv4 中文/英文）随依赖安装。量化 CLIP ViT-B/32 需要
首次单独准备，约 156 MB 模型加分词文件；之后无网络连接也可分类，不需要 API 密钥：

```powershell
.\.venv\Scripts\python.exe scripts/prepare_offline.py --mirror
# 或首次启动同时准备
.\scripts\start.ps1 -PrepareOffline
```

不使用镜像时省略 `--mirror`。下载固定修订版，验证固定 SHA-256，再保存模型清单。
运行时只加载本地文件，不隐式下载，不向云端降级。模型缺失/校验失败会明确降级为
待复核。`models/` 应随离线部署包一起保留；删除后需重新准备。

分类维度独立：**内容形式**（文本文档/文档影像/界面截图/自然照片/设计素材/未知）+
**主分类与二级分类**。九个主分类、57 个二级分类的固定标准在
`backend/neatdrop/taxonomy.py`，包括票据、课程笔记/论文/试题、合同/简历、通知、
快递/订单/医疗/证件、人物/风景/美食/宠物/物品、海报/插画/表情包等。

文本使用最多 12000 个本地抽样字符，长文读取头、中、尾，文本 PDF 按最多四页分配额度；
图片保留 OCR 原图坐标，长图最多全图加五个局部视图，明确提示未覆盖或超预算区域。
标题/正文/字段组合权重不同，文件名只作弱线索；
冲突、否定语境与证据不足进入待复核。图片先本地 OCR，再结合轻量视觉场景候选；
不会进行人脸身份识别、猜测地址或自动判定文件可删除。自然照片无可靠标题时保留原名。
云端仍仅发送原来的 ≤1500 字符或缩略图，不包含本地 OCR 中间结果。

DOCX 读取正文段落与表格，PPTX 按幻灯片顺序读取文字，XLSX 读取可见工作表和
单元格文本/缓存值，UTF-8 CSV 读取字段。Office 解析只提取有界文字，不启动 Office，
不执行宏、公式、外链或嵌入对象。公式只显示文件已有缓存值，可能过期；无缓存公式、
隐藏内容和未覆盖内容会提示限制。预览和分类依据可显示段落、表格行、幻灯片、工作表、
单元格或 CSV 行位置。跨单元格证据按共同的行定位，不伪造成一个单元格内的字符范围。

银行材料、缴费凭证、税务材料、研究数据、工作演示、住房物业和旅行资料新增
多证据用途候选；它们仍需人工复核。格式本身不决定用途，空字段、否定或文件名线索
不足以形成新用途。七类开发对照及其限制见
[v7 用途候选报告](docs/evaluation/v7-development-results.md)。该报告是相关合成样例，不能作为真实总体准确率。

v8 增加自然学习记录、研究叙述、共同讨论与责任分工、业务台账的结构候选，以及
“需求说明”“账户业务办理确认”等同义表述。只出现用途标题不会成为普通建议；
发票还要有可核对的主体及票号或金额字段。空值、备注数字与不同表格/工作表的内容
不能拼成一份有效凭据。新结构均为待复核候选，详情显示连续原文和可用位置。
对照及限制见 [v8 开发对照](docs/evaluation/v8-development-results.md)。

在 `.env` 设置 `NEATDROP_SEMANTIC_CANDIDATES=1` 后重启；所有语义建议仍需复核。
模型已安装/自检就绪与实验开关独立显示。离线推理不下载、不上传、不静默转云端。
模型、分词与 OCR 权重验证后安全加载；原生推理使用受限子进程，超时/取消会终止进程。
Python socket/DNS 禁止已做真实推理验证；本轮未配置 OS 防火墙或抓包，不能据此宣称
完成操作系统级出站网络验收。

策划、实现与评测见 [离线分类提升策划案](docs/superpowers/specs/2026-11-03-offline-classification-improvement-design.md)、
[开发集报告](docs/evaluation/2026-11-03-development-report.md)。运行可复现对照：

```powershell
.\.venv\Scripts\python.exe scripts/evaluate_offline.py --manifest docs/evaluation/development.json --output .cache/evaluation.json
```

附带 40 个手写合成开发场景，未充当 300–500 份代表性样本或冻结测试集。报告保留匿名
样本摘要、模型版本和源码配置指纹；使用文件路径样本时基线仅对比旧分类器，提取器共用新版。

CLIP 为英文提示词的通用轻量模型，复杂中文截图、低清图片和混合内容仍可能误分类。
OCR 识别分数、规则权重和图像相似度均**不等于准确率**。当前仅有回归样本与少量实际
推理验证，尚无代表性用户资料冻结评测集，不宣称“离线分类已达到某准确率”。

## 支持范围

| 项目 | 边界 |
| --- | --- |
| 图片 | JPG/JPEG/PNG/WebP 静态图片，最大 20 MiB；本地 OCR + 可选量化视觉模型 |
| 文本 | UTF-8 TXT/Markdown；未知编码、疑似二进制不上传 |
| PDF | 有文本层，离线按前两页、中间页和末页取最多四页；云端仍前两页和末页；扫描、加密、损坏 PDF 明确报错 |
| DOCX/PPTX | 正文段落/表格和幻灯片文字；不渲染Office版式，不识别其中的图片；隐藏、辅助或未覆盖内容提示限制 |
| XLSX/CSV | 可见工作表文本/原始值/公式缓存；UTF-8 CSV逗号、分号或TAB字段。不计算公式，不执行CSV字段 |
| 目录 | 只扫描直接子项，不跟随符号链接/Windows 重解析点，最多列出 2000 项 |
| 单批 | 最多 50 文件、单文件 20 MiB、合计 200 MiB |
| 分类 | 九个主分类 + 二级分类；单个归档位置，可有辅助标签 |
| 本地推理 | 多证据规则、中文/英文图片 OCR、CPU CLIP；未知/冲突需复核 |
| 暂不支持 | 递归、原位移动、删除、旧DOC/XLS/PPT、HEIC/GIF、扫描PDF OCR、宏/加密/危险外部关系容器、ICS、自动去重、后台监听 |

## 安全与恢复

2026-11-03 已补充后端安全加固。完整发现、修复与剩余边界见
`docs/backend-security-2026-11-03.md`。

- 同源服务绑定 `127.0.0.1:8765`，限制 Host/Origin，HttpOnly/SameSite 会话及 CSRF
  令牌保护写接口，并核查实际客户端为本机回环地址。不同会话的目录和分析任务隔离。
  严格确认布尔值、请求大小/总时限/并发限制。**不能直接暴露公网或局域网。**
- 执行器使用固定类别映射，不接受模型路径或命令；限制 Windows 保留名、非法字符、
  扩展名变更、路径越界；检查大小写和 Unicode NFC 等价冲突。
- 计划确认后不静默改名，15 分钟有效、单次使用。源文件摘要变化则停止对应项。
- 目标独占创建（`O_EXCL`），流式复制、关闭/刷新、SHA-256 复核；原件始终保留。
- 同目录写入使用操作系统文件锁；每事务有独立的带序号/哈希链 JSONL 分步记录。
  哈希链检测不完整或普通破坏，**不是签名或防恶意篡改认证**。
- 自动撤回还须匹配本安装在 `.neatdrop-state/` 中保存的可信归档凭据及目标系统文件身份。
  伪造目录日志不能授权撤回；同内容但已被替换的文件也不撤回。**升级前的旧记录只读，
  不再自动撤回**，原件与旧副本不做任何变更。请保留/备份 `.neatdrop-state/`，它不加密。
- PDF 在独立受限进程中解析，12 秒超时、384 MiB 内存上限；图片最多 2400 万像素。
  超限文件原地保留。模型必须使用 HTTPS，返回上限 256 KiB，不接受压缩响应。
- Office与CSV同样使用12秒/384 MiB独立解析进程并共享两槽准入。Office ZIP最多512成员、
  单成员解压8 MiB、总解压32 MiB、压缩比100:1；XML深度64、累计节点20万。危险关系、
  DTD/实体、宏和嵌入对象拒绝解析。CSV有字段/行列/总单元限制，完整预算见
  [新增格式解析报告](docs/superpowers/plans/v7-formats-report.md)。这些限制可能拒绝复杂但有效的Office文档。
- 目录扫描最多枚举 2000 项且最多校验 200 MiB 内容；超预算项会标注跳过。
  每目录最多 500 条历史项，达到上限时在复制前停止，已有记录仍可查看。
- 日志失败、中断或部分失败后，重新选择相同目录，在“操作记录”核对源与目标。
  应用不会盲目重放、删除残留或覆盖冲突。人工确认保留现状后才允许下一次写入。
- 记录损坏时阻止继续写入，需人工检查原件、目标与记录；不要直接删掉记录绕过提示。
- Windows 操作固定根目录与路径祖先的目录句柄，防止执行期间目录被替换；元数据
  使用不跟随重解析点、拒绝硬链接的受控句柄写入。撤回用禁止其他写/删除共享的
  文件句柄核对摘要，然后执行不覆盖的句柄重命名。修改、占用或冲突项保留。
  **文件执行与自动撤回仅在 Windows 开放**；其他平台仅提供扫描、预览和分析。
- 程序不是对抗拥有同一目录写权限的恶意本地程序的安全沙箱。应在自己有权管理的
  普通本地目录使用；网络共享、并发替换目录、硬件损坏不在可靠性承诺内。
- `.neatdrop` 内记录含路径与文件名，不加密，也不保证 Windows 隐藏属性。
  所有副本、记录及撤回文件均保留，应用不自动到期删除。

会话保留 8 小时，分析完成状态约 15 分钟。服务重启会清空授权、分析和计划，
需要重新扫描；磁盘上的文件与操作记录不会因此消失。

## 升级与卸载

升级前停止服务并备份 `.env`、应用 `.neatdrop-state/`、待整理目录及其 `.neatdrop`。更新源码后重新执行启动
脚本安装锁定依赖并构建。不要在存在未核对中断事务时直接清除目录记录。

卸载时停止服务，移除本工程和其独立 `.venv` / `node_modules` 即可；
用户目录的原件与归档副本不受影响。是否保留 `.neatdrop` 必须自行决定：移除日志会
失去应用内记录和撤回依据；撤回区中可能仍保存有用文件，请先检查。
