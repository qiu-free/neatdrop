# 本地与网页能力说明

| 操作 | 本地完整版 | 网页体验 |
| --- | --- | --- |
| 输入 | 用户授权目录，现有支持格式 | 合成学习样例或主动选择TXT/MD，最多10份、512KiB/份、2MiB合计 |
| 分析 | 生产规则、已准备OCR/视觉、可选实验语义 | Worker实际运行学习文本规则子集，每份最多12000字符，均需复核 |
| 图片 | 已验证的本地模型包推理 | 4份原创合成图片的本地处理预录结果，明确标识 |
| 扫描PDF | 可选依赖+明确开关，最多4页/60秒 | 无实时PDF/OCR |
| 保存 | 独立确认后复制，不覆盖、保留原件 | 仅内存归档，无真实副本；可导出JSON/CSV元数据清单 |
| 撤回 | Windows身份与摘要核验后移入撤回区 | 移除本页内存结果，刷新即清空 |
| 图谱 | 当前目录或全部主动登记且已授权目录 | 本页内存资料，按实际正文词项计算关系候选 |
| 隐私 | 回环会话、目录授权；在线另行逐批确认 | 不请求本地API或云端，不持久保存输入正文 |

两套构建各自校验：本地不包含体验样例/Worker，网页不包含本地会话传输。网页不是浏览器中的完整文件系统管理器。
