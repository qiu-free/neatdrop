# NeatDrop 日常使用指南

## 从目录到结果

工作台上方的六阶段流程与新手导览、安全练习一致：选择、分析、复核、计划与复制、
资料库、记录与撤回。练习内有可查看的合成内容、审核和独立确认按钮，完成后也能练习
查阅和撤回；全程只使用浏览器内存，不访问真实文件。可以随时跳过、返回或重播。

1. 在工作台选择本地目录，也可以粘贴完整路径后扫描。只列出直接子项。
   检查可处理数量及跳过原因，再勾选资料。初始不自动选择文件。
2. 默认使用离线分析。界面区分 OCR 与视觉模型状态；缺少模型不会自动
   上传云端。可跳过分析，逐项手动编辑和核对。
3. 点击文件打开右侧详情栏，复选框只表示加入批次，“已核对”表示已确认名称和分类。
   三者独立。搜索或筛选后，批量选择只作用于当前可见项。
4. 核对名称、主分类、子分类和内容证据。复核页可“一键审核已选项”，确认所选文件
   当前显示的分类与名称；候选也会按当前选择确认。未分析且未编辑或仍有分析错误的
   项目不能批量通过。需要修改时点击文件，批量改类和重新分析在“更多操作”中。
   更改名称或分类、重新分析会清除对应核对状态。
5. 生成计划，检查固定的原名与目标相对路径，重新勾选确认后生成副本。
   副本仍占空间，原件始终保留。
6. 结果页展示实际成功、失败及未执行数量和目标。操作记录可以核对磁盘
   事务，并在可信凭据及文件身份匹配时撤回未改动副本。
7. 打开“资料库”按分类筛选和搜索归档副本，点击文件在侧栏预览。
   副本实际保存在原目录内的分类子目录，网站只提供本机浏览，不上传文件。
   刷新或重启后重新选择同一目录，已有副本记录仍可查看。

每批最多 50 项、200 MiB，单文件最多 20 MiB。超限选择会保持原有选择，
请缩小筛选或分批处理。返回上一步保留本轮编辑；切换或重扫目录会清除
草稿，需要再次确认。刷新页面、会话到期或服务重启不会恢复资料草稿。

页面之间切换会保留本次会话的草稿、阶段、筛选与滚动；资料库等待记录加载后恢复滚动
位置。离开页面会取消过期预览，返回时不会自动重新打开详情栏。短动效不阻塞点击，
系统设置“减少动态”时停用非必要过渡。

图片较多的批次默认显示固定网格，可以切换文件列表。卡片中的“查看”只切换详情，
复选框只表示加入批次。待复核文件可以勾选，分析后保留选择；只有明确审核后才能
生成计划。详情的图片支持适应窗口和放大到 300%，显示的是本地有界预览，不是原图
分辨率。缩放不会改变文件；切换文件恢复适应窗口。

资料库最多显示最近 1000 份副本。已撤回文件不显示；丢失、替换或缺少本机可信凭据
的记录会提示不可用。列表不逐份校验内容，点击预览时再次核对文件身份和内容摘要。
在外部修改过的副本不会被作为原归档内容继续预览。需要查阅其他目录时，返回工作台
明确选择该目录；资料库不会自动扫描其他位置。

“建议放哪里”显示当前来源目录中的具体分类子目录。名称冲突或非法名称可能让最终
路径调整或被拒绝，因此执行前仍须核对计划。子文件夹数量单独显示，当前不会进入；
需要整理子文件夹时，单独选择它作为来源。副本和撤回区都占用磁盘空间。

分类现由服务端统一提供，共九个主类、57 个子类。可搜索图表、实验、需求、保修等
用途，并查看定义与正反例。“学习科研”“工作项目”视图只筛选常用入口，不迁移旧
文件夹。新增类别支持手动归档，不代表每种内容都已有自动识别规则；文件格式支持
新增内容提取支持 DOCX、PPTX、XLSX 和 UTF-8 CSV；静态图片、文本型PDF、TXT/Markdown
沿用现有路径。格式只决定读取方法，不代表它一定属于某个存档用途。

DOCX可读取正文段落与表格；PPTX按幻灯片顺序读文字；XLSX读取可见工作表和单元格，
公式只读文件已保存的缓存值（可能过期）；CSV按实际字段读取，含引号和跨行字段。
不会启动Office、执行公式或访问文档外链。隐藏、无缓存、超出读取额度等情况会在
“读取范围”说明。证据可以定位到幻灯片、表格行、工作表/单元格及CSV行；表格空列
会保留边界，不会拿后面的备注当成字段值。

旧DOC/XLS/PPT、宏/加密/嵌入对象/危险外链容器、扫描PDF OCR、HEIC/GIF仍不支持。
Office版式和内嵌图片不会被完整渲染；复杂容器超过安全上限会停止解析并给出原因，
原文件保留。项目选择器显示当前后端真正提供的格式能力；旧服务需正常重启后才加载新增解析器。

图表分析增加散点、折线、柱状、直方、饼图、热图、箱线、流程图等本地视觉候选。
内容形式与归档用途分别显示，未校准候选始终需要人工核对。不会还原数值、解释趋势，
或把零星 OCR 文字编造为标题。没有可靠标题时保留原文件名。

v8 可以根据“学习过程＋学科内容＋练习推导”“共同讨论＋责任分工＋后续约定”等
组合提供候选，不再要求资料一定写着“课程笔记”或“会议纪要”。业务台账需要业务
上下文、表头和同一区域的实际数据行；CSV/XLSX后缀本身不代表办公用途。
这些扩充能力仍需复核。只有标题、发票字段为空或只有备注说明时，详情会提示
证据不足；“内容已读取”不表示用途已确认。教程引用票据/合同示例时，优先核对
整份教程的学习用途。扫描PDF、分散OCR字符和个人归档偏好仍有待后续专项改善。

## 用知识图谱查阅关联资料

完成归档后，从导航打开“知识图谱”。默认全局图谱用分类颜色聚合圆形节点，
右侧“分类分组”显示各组数量。分类分组是已有归档类别，不能视为算法发现了
主题或知识事实。拖动画布、滚轮缩放，或使用放大、缩小和适合画布控制。
文件较多时按组继续显示；画布显示数量受限时，文件列表仍能搜索并打开全部返回结果。

点击文件节点或列表项，在右侧查看已核验的归档副本。需要围绕一份文件查阅时，
切换到“局部关系”。资料库详情也提供进入同一文件图谱的入口，图谱详情可返回
资料库。窄屏详情占满页面，Escape 或关闭按钮返回；可使用文件和关系列表完成操作。

初次进入只使用已有归档分类和归档时的重复内容记录。要分析正文、图片文字或
视觉线索，点击“分析关联”，选择最多 50 份副本并勾选本机保存说明。每份最多
20 MiB、每批合计最多 200 MiB，文字沿用有界采样。没有可靠文字的照片不能据此
得到主题描述。图片视觉相近只说明感知指纹接近，不能认定人物、地点或事件。

关系有三类来源：归档记录中的内容相同、待确认的本机相似候选、人工维护的关系。
候选用虚线标记。点击“查看关系依据”核对双方当前副本、读取范围和共同线索后，
再决定确认或忽略。相似度分值只用于排序，不是准确率。手动添加引用、配套说明
或版本关系时，先核对表单中两个文件的方向。

分析进度支持取消；取消不会发布这批未完成的索引，已有有效快照保留。
“管理本机索引”可以清除提取特征及自动候选，正常状态下保留人工关系和所有文件。
索引文件损坏时，重建无法恢复损坏文件里的人工关系，需重新添加。
本机索引只保存有限关键词、位置、内容摘要与图像指纹，不保存正文、原始 OCR 或图片。
安装目录中的 `.neatdrop-state/knowledge-graph/` 需要与可信归档凭据一起妥善保留。

图谱最多返回当前目录最近 1000 份归档副本，画布同时最多 200 节点，局部视图最多
20 个邻居。自动候选两端各最多 5 条，密集大批资料可能漏掉关联。列表与旧索引只
反映历史记录，不证明磁盘内容未变化；预览、查看关系依据及确认候选都会重新核验。
撤回的副本及其关系不会继续显示。

## 遇到中断或失败

- 分析失败：检查逐项原因，只重试失败项。云端重试必须再次授权。
- 取消分析：保留已经完成的建议，未开始项不再分析。已发出的云端请求
  可能仍计费。
- 复制连接中断：查询执行状态和操作记录，不能重复点击发送复制。服务
  重启后重新选择相同目录检查记录，确认现有副本后再生成新计划。
- 源文件变化：原件保留，重新扫描和核对后生成新计划。
- 目标冲突：不会覆盖目标，检查记录和目标后重新生成计划。
- 日志、可信凭据或磁盘写入异常：停止后续写入。保留原件、副本和记录，
  在操作记录逐项核查；应用不会自动重放或删除残留。

撤回会将副本移入 `.neatdrop/withdrawn/<事务ID>/`，不会删除文件。被修改、
替换或占用的副本保持原状。旧记录缺少当前安装的可信凭据时只读。

## 模型设置

离线建议现在会显示“内容读取质量”。“内容已读取”只表示本次提取未触发已知限制，
不等于用途已确认；“读取受限”会说明乱码、文字不足、OCR 分值偏低或只读取部分内容。
受限内容不会直接给普通建议，也不会用低质量文字自动替换文件名。自然照片或图表没有
OCR 文字是正常情况，不会只因无文字就否认图像类型。读取信息中的字符数和文字行数
用于核对覆盖情况，不能当作分类准确率。

实验资料、技术文档、读书摘录、项目方案、需求设计、邮件存档、保修说明和保险资料
增加了明确内容锚点与至少两组不同字段的离线规则。新规则只提供待复核候选；文件名
或孤立标题不足以触发，教程/模板和混合用途仍需核对。首次实现的规则尚未经过独立
真实资料校准，不代表57个子类已全部具备可靠自动识别能力。

银行材料、公共服务缴费、税务材料、研究数据、工作演示、住房物业和旅行资料也已
增加候选规则。缴费要求具体费用项目和完成状态；研究数据要求研究背景与观测/变量
证据。空值、未采集、否定、模板和邻类冲突均须单独处理。新用途全部保持待复核，
不能用规则分数或相关合成开发集的命中数量宣称真实准确率。

离线详情现在区分普通建议、待复核候选和暂不判断用途。候选按钮只更新草稿分类，
不会自动确认；选择后旧确认与计划失效。主类已有依据但子类不清楚时，可选择仅按
主分类归档并逐项确认。拒判项保留原名，避免凭内容不足的片段猜名称。

长文本读取头、中、尾，文本 PDF 最多抽样四页，长图最多六个 OCR 视图。详情中的
“读取范围”说明实际覆盖情况；看到未完整读取或预算提示时，应结合原文件核对。
OCR 证据可带原图局部位置，文本证据可带页码/字符范围。识别分数不等于分类准确率。

本地 BGE 语义候选包需要按 README 单独准备或从本地导入，运行时不会下载。
默认 `NEATDROP_SEMANTIC_CANDIDATES=0`，因为当前开发集未显示比增强规则更好的质量。
设为 `1` 并重启才会参与分析，所有语义结果保持待复核。设置中“模型已就绪”表示
文件校验与合成输入自检通过，不代表识别质量经过代表性评测。

取消会停止后续工作并请求终止本地受限推理进程；保留已完成结果。模型缺失、损坏、
权限异常或预算受限会明确降级，不上云。真实资料不会从编辑操作中自动收集训练。

在“模型设置”查看离线状态。云端可选百炼预设或自定义兼容服务，仅支持
当前 OpenAI Chat Completions JSON 协议。填写服务 HTTPS 基址、文本和视觉
模型名、每批请求次数及密钥。保存仅进行本地静态校验，不会连接服务。

密钥与服务地址绑定。保留密钥时不能更换地址；更换地址必须重新提供密钥。
“移除密钥”清除本机界面配置的密钥，环境变量中的密钥需要修改环境配置。
环境变量优先，覆盖字段会锁定，环境密钥生效时服务地址也锁定。

Windows 当前用户 DPAPI 加密配置保存在应用私有状态目录，与撤回凭据分开。
密钥不通过查询接口返回、不写入浏览器存储或普通配置文件。解密失败时
显示未配置并锁定界面写入，不会降级保存明文；检查系统权限和原配置，
必要时使用环境变量提供新配置。不要将加密文件视为可跨用户
恢复的备份，跨账户或系统重装后可能需要重新配置。

“测试连接”须主动确认目标及可能计费后执行，只发送固定示例文本。测试
成功只说明文本接口可调用，视觉模型需要另行验证。自定义地址拒绝本机、
私网和其他非公网解析结果，连接固定到已验证地址，保留服务主机名的 TLS
校验，禁用代理和重定向。

每个云端任务固定配置快照。更改配置后，下一任务需要再次授权。云端只
收到去除 EXIF 的小图或最多 1500 字的抽样文本；不会发送原件和绝对路径。

## 教程和隐私

首次进入提供六阶段导览，可以跳过，也可直接开始安全练习，之后可从教程中心重播。
演练使用内存中的人工样例，持续标注“演练模式”，每屏展示本步目标、阶段图和操作。
收据与课程笔记均可独立练习；查看所选副本后可明确完成核心练习，记录与撤回作为可选练习。
不读取真实目录、不调用API或文件写入。跳过不记作完成；旧版已关闭导览的记录保留
为旧版关闭状态，实际完成练习后才出现练习完成徽标。侧边栏“产品说明”集中说明用途、
工作流、保存位置、离线/在线边界和资料库/图谱价值；打开说明或练习不会清除当前工作台草稿。

浏览器仅保存经过校验的界面密度、离线优先偏好和版本化教程进度。文件名、
路径、内容预览、计划和密钥不写入浏览器持久存储。页面草稿仅在本次会话内存保留。
浏览器存储不可用时仍可
使用；刷新后可能再次出现首次导览。密度默认舒适，系统“减少动画”偏好
会减少界面运动。
