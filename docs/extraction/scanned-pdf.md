# 扫描 PDF 的有限页离线 OCR

文本 PDF 继续使用既有文本提取。没有可读文本层的 PDF 可在本地启用扫描 OCR，默认关闭，云端抽样不受影响。

安装可选依赖：`uv sync --extra pdf-ocr`；当前固定 `pypdfium2==5.14.0`。Python 包采用 BSD-3-Clause/Apache-2.0，PDFium 及其附属组件的许可证随 wheel 分发，发布工程包必须保留它们。网页体验包不包含这个原生依赖。

在启动本地服务前设置 `NEATDROP_SCANNED_PDF_OCR=1`。OCR 模型仍须已在本地准备并通过原有完整性校验；此开关不会下载模型、调用在线模型或建立网络授权。关闭环境变量后恢复默认文本 PDF 行为。

扫描文件先经原有受限解析器校验加密、页数和文本层。无文本时抽样前两页、中间页和末页，去重后最多4页；每页最多400万像素，按页释放。PDFium 渲染进程沿用384 MiB内存上限，OCR沿用1536 MiB及现有并发限制；整个文件父级总时限60秒，取消会停止当前受限子进程。没有读到的页面明确列为部分覆盖，不能根据样本页假定全文内容。

依据保存抽样页码、实际识别文字框和片段。OCR分值是识别线索，不表示分类准确率。手写、公式、低清图和复杂版面仍需核对；没有可用文字时拒判，Office内嵌图片不在本次支持范围。
