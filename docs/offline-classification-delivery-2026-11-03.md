## 已交付的行为



- 长文本最多 12000 字符，按头、中、尾分配配额，片段之间保留换行，记录原字符位置。文本层 PDF 离线最多取前两页、中间页和末页，单独分配额度；云端取样边界保持原值。
- 图片先保留全图，长图最多追加五个 OCR 局部视图；保留原图坐标，重叠区域去重，按预算保留头中尾识别行。CLIP 采用全图 letterbox，有限局部视图只作补充。
- 新增无固定标题的论文与数学笔记结构候选；论文写作/格式教程、票据教程、证件示例、壁纸设置教程等必须复核。自然照片不会被零星 OCR 标牌改名；拒判项保留原名。
- 规则与语义分开产生候选，决策层不相加不同类型的分数。候选接近、引擎冲突、内容未读全和主类明确子类不清楚时逐项复核；语义候选始终未校准。
- 详情显示普通建议、待复核候选、暂不判断用途、最多三个有效候选和读取范围。选择候选只编辑草稿，使原确认与计划失效，需要重新确认。
- 实现并准备固定版本 BGE small 中文 CPU 候选包，提供单独下载/本地导入命令。语义模型默认关闭，设置页独立显示模型自检和实验开关。只有 `NEATDROP_SEMANTIC_CANDIDATES=1` 才参与产品分析。
- 增加明确清单驱动的评测器、40 份手写合成开发资料、旧分类器基线、匿名 JSON/Markdown 对照。拒判、失败、降级与范围外假阳性均进入报告。

## 模型与资源保护

BGE 包：`Xenova/bge-small-zh-v1.5`，revision `75c43b069aac4d136ba6bc1122f995fedcfd2781`，MIT，完整包约 24.5 MB。量化 ONNX SHA-256：`15b717c382bcb518ba457b93ea6850ede7f4f1cd8937454aa06972366cd19bcc`。保留原始模型卡与池化配置，采用 CLS/L2；最多六块，每块含特殊 token 不超过 384，重叠不超过 48。

模型存在不代表就绪：语义包必须通过可信摘要和真实 CPU 自检。权限异常、损坏、分词不匹配或资源不足会降级。ONNX 与 tokenizer 使用已经校验的不可变字节；RapidOCR 需要文件路径，因此在校验至构造期间固定 Windows 模型文件与祖先目录，防止替换。

图像推理使用一次性子进程，硬上限 25 秒/1536 MiB；语义推理总期限 12 秒/1536 MiB，包括锁等待、首次自检与推理；PDF 保留 12 秒/384 MiB。图片/PDF/语义取消会终止实际解释器进程，相关 PID、超时、内存限制和并发槽恢复已有回归。Windows venv launcher 不作为实际 native worker PID 的替代。

完整性固定和可信撤回保证针对本轮 Windows 目标环境验证，不把 Windows 文件共享句柄语义推广为 POSIX 同等保证。程序仍不提供对抗拥有同账户任意代码执行权限的恶意程序的沙箱。

可选语义能力失效时，会显示降级警告并在评测中单列。若独立的强规则仍有充分证据，可以保留原规则建议；不会用失效语义引擎支持原本缺证据的分类。

增强规则在缺少固定标题的两个目标场景上补出了可用候选，保护门槛也增加了需要人工复核的文件。因此不能将“普通建议零错误”单独宣传为质量全面提升：普通建议覆盖也从 70% 降为 55%。新版 22 份普通建议零错误的 Wilson 95% 上界约 14.9%，明显不能证明策划案要求的 ≤3% 发布门槛。

语义模型没有增加该开发集的正确首选/Top-3 命中，部分新增候选仍不准确。因此没有纳入默认引擎；模型可用性、资源和完整性实现已交付，质量仍属实验。普通短文本 fresh-worker 约 1.1–1.3 秒，六块输入约 1.5 秒，单次独立 worker 峰值 RSS 约 203 MiB。实际完整开发集耗时以 JSON 报告为准。

安全字节加载后的真实 OCR/CLIP 复审样本用时 4.328 秒、峰值工作集约 567 MiB；早期路径加载版本约 345 MiB，不能把早期数值当最终资源承诺。上述为合成样本观测，不代表长图最坏耗时或全硬件兼容。
