本轮不重新换肤，沿用MASTER蓝白主题、五个导航目的地及现有操作规则。原件保留、副本独占创建、CSRF/Host/Origin/会话约束不放宽。

验证记录：Task1初次后端全量870通过、2跳过。前端初次355通过后，审查发现导入生命周期和集合索引取消/分页问题；现已修复，并增加延迟读取、迟到任务创建、跨目录取消、退出范围取消和后续页修改关系的回归用例。

前端最终全量：`npm test -- --run`，**53个文件、369项测试全部通过，18.44秒**。其中新增跨页面恢复用例覆盖：任务创建迟到、登记刷新、首次取消失败、离开整个图谱页及返回重试。`npm run build`与`npm run build:experience`均成功，本地包排除网页样例及Worker，网页包22份静态文件排除本地API传输，并附第三方许可声明。键盘用例保留真实懒加载画布与焦点断言，初次全量中的1秒启动等待超时已调整为5秒后重跑通过。

后端最终全量：`python -m pytest -q --tb=short --basetemp .cache/comprehensive-final-backend-reviewfix -p no:cacheprovider`，**925通过、2跳过，154.04秒**。包含短文本PDF兼容、扫描回退、跨会话授权/撤销、子目录替换、配对元数据中断恢复及原执行器安全回归。跳过为既有平台条件测试，不能解释为所有平台能力均已验证。

最终整轮审查发现并修复两项：混合文本/扫描PDF现在逐个抽样页检查文本，不允许封面大量文字掩盖其他页的提取不足；目录在两次集合读取之间离线时会省略失效条目、清理悬空边并标明截断，游标按已消耗页段推进。两项均先复现失败，再修复；相关测试46通过，随后运行上述全量。最终修复复审无新增可执行问题，前端跨页面恢复的专项复审也已通过。

真实本地集成：专用合成双目录同名归档、内容相同依据、撤销授权阻断、原身份重授权、A撤回不影响B、原件SHA-256不变全部通过。测试不读取个人文件。

最终服务重启后再次运行`python scripts/verify_catalog_local.py`，上述双目录验收全部通过。实际浏览器对50份合成归档条目开始集合索引后取消，只发送一次取消请求。取消响应为`cancelled`、24/50，随后服务状态为`cancelled`、25/50，说明一个已在处理中的条目完成收尾；未继续处理整批。更窄的迟到创建、下一目录派发和退出范围竞态由确定性延迟回归覆盖。

扫描PDF合成实测：5页栅格论文页，抽样1/2/3/5页，23.672秒、555字符，论文候选且需复核，依据有真实页码和框。该单次结果不是P95或准确率。

网页实测：8文本首次计算约1251毫秒，内存独立确认与导出、关系依据可用；实际导入笔记与实验内容分别得到不同子类，localStorage无正文。1440×900、1024×768、768×1024、390×844、844×390、720×450有效布局宽度均无整页横向溢出。最后一个是200%等效布局宽度检查，尚不等于操作系统/浏览器实际缩放验收。减少动效生效，关系抽屉Tab/Escape可用。

最终前端构建再次实际走通8份文本分析、人工核对、独立确认加入内存资料库和真实词项匹配，生成8节点、5条候选曲线；资源记录无`/api/`调用，localStorage为空。另实际导入文本并清空，文件消失且没有本地服务请求。

切换稳定性：实际连续30次文件切换的正文与当前文件一致，预览容器均为280px高；连续30次页面切换后没有遗留弹窗/inert。实际本地集合预览成功，撤销集合授权后回工作台的目录与文件列表保留；单独确认打开子目录后仅枚举该层。

200节点合成图谱：通过真实HTTP执行4批×50份副本（原件摘要不变），画布展开200节点、150条归档内容相同关系，实际点击节点打开正确预览。已保存并检查适合画布截图。空闲事件循环16ms定时器99次间隔P95约17.5ms；requestAnimationFrame采样在当前Ego自动化环境超时，因此这不是帧时间P95，未将其作为稳定60fps证明。密集图仍建议搜索、局部关系或减少展开项。
