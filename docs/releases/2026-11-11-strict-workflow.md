# 工作台按步骤校验

日期：2026-11-11。用户要求每一步严格执行，不能从第1步直接跳到后续步骤。本轮修改现有流程约束，沿用蓝白主题、五个导航目的地和原文件操作协议。

| 当前环节 | 进入后续环节的必要条件 |
| --- | --- |
| 选择 | 已载入目录或网页资料，并勾选至少一个可处理文件 |
| 分析 | 所有当前已选文件均已有分析建议、无未处理错误，分析任务已结束 |
| 复核 | 当前已选文件的分类与名称全部经人工确认；修改后重新确认 |
| 计划与执行 | 真实生成计划成功后才进入计划阶段；路径核对与独立勾选确认仍为必要条件 |
| 资料库 | 本次执行已结束且有成功项 |
| 操作记录 | 本次执行已结束；无成功项时仍可检查失败记录 |

第1步和第2步的侧栏保留内容预览，编辑与逐项确认在第3步才启用。导航按钮与底部操作采用相同条件，不会因部分结果、手工编辑或旧页面状态提前解锁。新增未分析文件会回到分析环节；没有实际计划或执行的旧结果页会回到有效环节。计划生成失败时保留复核页面。

执行状态为planned/queued/running但连接失败释放busy时，工作台仍保持结果恢复环节，步骤跳转、目录替换、重新扫描和文本替换均锁定，只查询原计划，不重复执行。左侧资料库/图谱等独立页面仍可浏览已有资料，不代表跳过本批整理。

验证：先添加7个防跳步回归，修复前7项均失败；审查发现断线执行旁路后添加3个恢复回归，修复前3项均失败。专项复核已通过。实际浏览器使用原创合成目录：未选择及未勾选时第2–6步锁定，勾选只解锁第2步，分析后仅解锁第3步，修改已审核名称会重新锁定计划，执行确认默认未勾选，独立确认后实际生成2份副本，再解锁资料库与记录。390px视口无整页横向溢出；截图因Ego窗口最小化未取得，不把DOM检查写为视觉截图验收。

最终验证：`npm test -- --run`，53个文件、380项全部通过（14.20秒）；`npm run build`与`npm run build:experience`均成功，两个产物隔离检查通过。Impeccable机械检查返回空问题列表，`git diff --check`通过。后端和文件执行协议未改动，本轮没有重跑无变更的后端全量。
