# 本地目录选择与子文件夹入口修复

## 使用变化

- Windows 使用独立 STA 进程打开带地址栏的系统文件夹窗口，避免在 ASGI 工作线程中直接维护 Tk 窗口。系统输出按 UTF-8 读取，忽略非 UTF-8 诊断流对结果读取的影响。
- 取消返回未选择；并发打开和等待超时分别提示重试方式。仍可粘贴完整目录路径扫描。
- 工作台列表和网格直接提供文件夹入口，沿用切换目录前的草稿确认。确认后扫描子目录，支持的文件可继续勾选。
- 文件夹不加入分类批次；仍然不递归扫描。任务进行时禁止切换目录，网格键盘导航会跳过不可用入口。
