# 板块主题与平滑侧栏

2026-11-12。按用户提供的圆角工作台参考图完善现有 NeatDrop，保留蓝白配色、五个页面、数据和离线分类工作流。

## 变化

- 浅蓝环境背景由本地静态 CSS 绘制，导航保留蓝色玻璃，主工作区为独立圆角表面。目录、文件列表、资料库、图谱、记录、帮助和模型设置统一面板表面、圆角及边界。
- 大屏外围20px、侧栏与主区间距16px；中屏16px / 12px；手机外围8px。主区内间距、控制尺寸与文字系统沿用 `MASTER.md`，不更换主色、导航或业务步骤。
- 侧栏和工作区在支持 View Transitions 的浏览器使用260ms快照过渡，页面切换使用180ms轻量淡入。按钮按压和方向箭头使用原位轻反馈，不改变点击区域。
- 连续切换取消旧动效，并用递增版本和最后一次意图防止旧回调覆盖新选择。无API、减少动效、同步错误或快照回调失败时直接落实状态。处理 `ready` / `updateCallbackDone` 拒绝，避免浏览器超时报未处理异常。
- 保留目录草稿、文件会话和偏好白名单；主题与动效不触发文件操作。没有增加依赖、远程字体、在线脚本或后台循环动效。
- 知识图谱展开及手机设置面板临时提高主区层级；图谱的浮层和展开态不被面板裁切。文件详情使用现有语义遮罩色，关闭操作仍在原位置。
