# NeatDrop v4 实施与验证

承接已确认的日常使用完善计划与 `../specs/2026-11-03-taxonomy-workbench-image-v4-design.md`。本轮直接实施已确认的信息结构，沿用现有森林绿界面，借鉴已查看的 Starter Kit 文件布局和 React Bits 原位状态反馈；不另起整站重设计审批。

## 全局约束

保留既有分类 ID 与目录；不改动原件；仍只扫描一层；复制、执行确认、摘要校验和可信撤回保持。离线不自动联网、下载或切云。用户实际图片不复制进评测集或上传外部服务。无 Git 仓库，在当前目录开发。

## 工作项

1. 服务端扩充已支持格式的常见用途；下发分类、定义、目录及内容形式。提供由后端生成的前端冷启动快照，前端运行时使用 config 分类，杜绝手工重复维护。
2. 现有 CLIP 加图表类型提示与保守融合。图表形式与归档用途分别表达；未校准类型保留人工确认，文件名不能单独证明图表用途；不生成图中数值或趋势。不增加格式解析。
3. 分类搜索、目的地预览、来源与子目录说明；待复核可勾选，未确认不能生成计划；编辑仍清除确认。
4. 图片批次固定网格与列表切换；详情提供固定预览框、放大/缩小/适应窗口，技术证据折叠。保留已修复的缓存身份、请求取消、焦点和滚动稳定行为。动效限短时颜色/透明度，支持减少动效。
5. 测试先行：新目录/旧目录兼容、图表与照片冲突、分类搜索与路径、勾选与执行门槛、预览缩放与切换。完整 Python/Vitest/生产构建及桌面/窄屏实测。

## 验证边界

合成图片仅证明开发场景与回归，不声称代表真实总体准确率。更大模型、自定义分类、更多格式、递归、真实用户可用性访谈留待独立范围确认。
