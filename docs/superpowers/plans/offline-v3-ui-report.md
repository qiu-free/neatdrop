# 离线分类 v3：Task 4 界面交付记录

日期：2026-11-03。范围：已批准实施计划 Task 4 及设计稿第六节。

## 已实现

- `frontend/src/types.ts`：子分类允许 `null`；新增 `decision_level`、候选、抽样范围、引擎版本及可选证据位置类型；兼容旧配置的可选 `offline.semantic`。补充决策层实际使用的中文复核原因。
- `Inspector.tsx`：展示普通建议、待复核候选、暂不判断用途三种状态；主分类明确而子分类为空时解释“二级分类待确认”，保留仅按主分类归档。
- 候选区最多显示三个有效且不重复的候选。主类、子类必须存在于前端分类表且父子关系正确；未知 ID、跨主类子类及原型属性名不会成为候选标签。候选依据按普通文本展示，不显示相似度及百分比。
- 点击候选仅调用既有 `onEdit`，保留当前名称，允许 `subcategory: null`；不触发确认。分析过程中候选按钮与既有编辑、确认控件共同禁用。
- 读取范围显示后端提供的中文摘要；截断或预算耗尽时始终提示未完整读取、需要确认归档用途。证据项支持页码、字符段、图像局部区域说明；结构和语义有对应中文来源标签。
- `offline_semantic` 显示“本地语义依据”。根任务提供的 `subtype_ambiguous`、`engine_disagreement`、`partial_content`、`semantic_partial`、`engine_incomplete`、`unsafe_title` 均有中文说明。
- `SettingsDialog.tsx`：显示本地语义未安装、校验中、已就绪、自检失败、预算受限以及未知/待校验状态和版本。仅在 `available === true`、`state === 'ready'`、`integrity_check === 'verified'` 同时满足时显示已就绪。保留离线不下载、不上传说明，无安装或下载操作。
- `classification.css` 为独立新增样式，沿用森林绿；候选按钮为原生按钮，提供可访问名称、可见键盘焦点和至少 44px 高度，窄栏使用单列、可换行布局。

未修改 `useWorkspace.ts`、`App.tsx`、核心样式或后端。生产构建正常更新 `frontend/dist` 与 TypeScript 构建缓存；没有 Git 操作。

## 限制与集成交接

- 本报告未声称完成真实浏览器的桌面/移动端视觉验收。原生控件、焦点样式、单列布局及换行已实现；真实桌面/移动端流程由根任务最终集成验证。
- 语义状态依赖后端自检结果。前端不会从模型文件存在推断就绪，也不会主动初始化或下载模型。
- UI 不验证分类准确率；候选分数仍保留为接口元数据，无准确率展示。
- 后端若增加新的决策原因码，详情页将显示通用中文人工复核提示，建议随后补充明确文案。
