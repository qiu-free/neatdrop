# 资料库、批量审核与按需详情 v6

用户已要求直接开发、测试、验证。在 v0.5.0 基础上实现三个连贯行为。

## 资料库

主导航增加“资料库”。展示当前授权目录内由净匣生成的归档副本，支持主分类筛选、名称搜索、列表与点击后右侧预览。显示名称、分类、生成日期、来源和实际相对路径；执行结果提供“查看资料库”。记录来自本地持久日志和本机可信回执，刷新后重新选择同一目录即可再次查看。文件保存在本机，不上传云端。不保存用户目录到浏览器持久存储。

API：GET `/api/v1/workspaces/{id}/library` 返回 `{items: LibraryItem[], truncated: boolean}`。LibraryItem 包含 `id`（不透明稳定 ID）、`transaction_id`、`name`、`source`、`target`、`category`、`subcategory`、`created`、`size`、`availability`（available/missing/changed/unverified）。最多 1000 条，按日期倒序，truncated 说明截断。GET `/api/v1/workspaces/{id}/library/{entry_id}/preview` 返回已有 Preview 格式 JSON。只有与本机可信回执一致且身份、尺寸、内容哈希仍符合的副本可以预览。列表允许显示不可用原因，但不能暴露任意路径或从客户端接受路径。已撤回项不列入资料库。列表无需逐文件哈希；预览重新核验并使用有界读取与安全解码。对目录、链接、替换、伪造日志、未知 ID 拒绝读取。

## 一键审核

复核阶段主要操作为“一键审核已选项（N）”。仅确认所选、受支持、已有分析建议或手动编辑且没有未处理错误的文件；包括需要人工确认的候选，明确说明确认当前列表中的分类与名称。尚未分析的文件先分析或编辑，不默认为其他后静默通过。已确认数和剩余待确认数可见。批量分类、重新分析收进“更多操作”。修改分类或名称、重新分析、选择变化仍使相应审核或计划失效。生成副本继续经过计划中的独立勾选确认。

## 按需侧栏

工作台与资料库的文件详情初始关闭。点击文件后在右侧打开；选择复选框只改变批次，不打开详情。桌面与移动端采用统一侧栏模式，关闭按钮、遮罩、Escape、焦点回到触发文件、Tab 焦点约束、背景滚动锁可用。切换文件保留详情容器和固定预览高度，避免闪烁跳动。页面导航后关闭工作台侧栏，保留整理草稿。保留现有主题、字号、预览请求上限和缓存。

## 全局约束

- 本机离线优先；不新增网络调用或模型下载。
- 原件保留；复制执行必须有独立最终确认；不新增删除操作。
- 资料库的文件读取只来自验证过的日志与本机可信回执，不能接受客户端文件路径。
- 保留现有路径、根目录身份、链接拒绝、读取预算、可信撤回与服务安全检查。
- 不引入新依赖；主题延续；桌面和移动端可访问。

## 验收

后端覆盖复制记录持久性、伪造日志、丢失/修改/替换副本、未知 ID、撤回。前端覆盖按选择批量审核与失效、初始无侧栏、点击/关闭/焦点/跨页面关闭、资料库筛选和预览。全量后端/前端测试及生产构建通过。使用合成文件实际完成分析→审核→确认复制→资料库→预览→撤回，核对原件哈希不变。
