# NeatDrop v7：新增格式、离线质量与清晰流程

用户已明确需求并要求继续：增加文件类型分类、提高离线准确率、新手能看懂并体验工作流、模块切换流畅。继承3b041c1方案的证据/安全约束，本轮主线为真实内容解析。

## 交付范围

1. 新增DOCX、PPTX、XLSX、CSV的本地有界内容提取、文本预览和离线分类。文件格式决定提取器，不决定归档用途。读取段落/表格、幻灯片文字、工作表标题/单元格文本/缓存值、CSV字段；未知/损坏/加密/危险容器明确报错。不执行宏、公式、外链、嵌入对象，不启动Office。扫描PDF OCR、旧DOC/XLS/PPT、HEIC/GIF及递归目录后续独立实现；帮助准确说明范围。
2. 补齐高价值用途候选：银行材料、缴费凭证、税务材料、研究数据、工作演示资料、住房物业和旅行资料。每类独立正向锚点、至少两组非空证据和相邻反例。文件名/扩展名单独不赋予用途。新用途始终candidate-only；保留质量、冲突、抽样与拒判闸门。
3. 四步文字导览升级为完整工作流总览与阶段化安全演练：选择目录和文件→离线分析→核对依据/改类/一键审核→核对计划并确认复制→资料库查看→记录撤回。清楚说明查看与勾选、原件/副本位置、分析不是执行。练习使用内存合成资料，无API/文件/模型访问；按钮与审核失效语义符合真实流程。可跳过/返回/重播；跳过与完成分开记录，兼容旧偏好。
4. 稳定导航及约140–200ms的短过渡：工作台/资料库/记录/帮助、整理阶段、侧栏切换。只动画opacity/transform，不动画布局尺寸，不阻塞操作；减少动态偏好关闭非必要动效。会话内保留工作台草稿、页面筛选和滚动；刷新不恢复用户路径/分析内容。预览禁止闪现前文件，旧请求取消；页面与侧栏焦点/滚动/inert正常恢复。

## 架构

提取器返回既有text/sample/truncated/sampling契约，segments可含page、slide、sheet/cell、row位置。离线最多12000字符，预览/云端片段最多1500；新格式云端仍需既有每次授权，不发送Office原件。解码使用有界子进程及两槽准入。Office ZIP限制成员数量、解压总量、单成员字节、压缩比，拒绝加密、越界成员、DTD/实体及危险宏容器。公式只读缓存值/无缓存明确说明，不计算。新依赖仅在现有标准库无法安全实现时评估，本轮优先零新增依赖。

扫描状态继续兼容supported/reason；新增格式真正成功提取时可分析。未支持/失败项给出原因与后续动作。资料库通过可信ID预览新增格式，保持同句柄身份/hash核验。分类画像、规则、UI和帮助一致，源文件扩展名大小写保持。

用户旅程共享阶段定义和文案，练习用相同语义的简化内存状态。公共页面切换控制协调滚动/焦点，不在每个页面重复创建无边界缓存。过渡只呈现当前可交互页面，不产生双份可聚焦内容；隐藏页面不能持续发起预览、锁住背景或覆盖新模态。

## 验收与测量

- 四新格式各有真实字节容器成功提取、分类、预览、复制、资料库、撤回测试；纯改后缀不算支持。损坏/过大/压缩炸弹/加密/DTD/外链/宏、超时取消、部分读取均测试。
- 新用途正例、同义表达、正文无标题、文件名仅命中、否定、空字段、教程模板、相邻混淆回归；旧冻结40场景不可静默退化。
- 保存当前Git基线与新版本的分组样例对照，报告主/子类命中、待复核、拒判、错误普通建议与分母；合成集只作开发回归，不声称真实总体准确率。没有授权代表性冻结数据的类别不升级普通建议。
- 新人5名目标测试：至少4名无协助在3分钟内完成内存演练，至少4名能指出原件/副本位置和确认步骤；未组织真人测试时必须标为未验证，不能用自动化代替。
- 桌面1440×1024、手机390×844和减少动态模式：无横溢；导航20次无空白/残留侧栏/草稿丢失；预览切换固定280px；快捷连点最终状态正确、无过期内容、无重复复制。目标过渡完成<=200ms，耗时任务展示真实进度，不伪造处理百分比。

## 全局约束

- 本地离线优先，不自动下载模型、不静默联网或云端降级。
- 原件保留、固定分类目录、独占创建、哈希校验、可信记录撤回和最终复制确认保持。
- 保留路径/根身份/链接拒绝、20MiB单文件、50文件/200MiB批次、两槽解析和有界子进程。
- 用户资料不写入浏览器持久存储，不自动采集真实训练/评测内容。
- 旧服务重启此前被拒绝；本轮不停止或重载该服务，验证使用已授权的独立进程内测试桥接，明确运行状态。
