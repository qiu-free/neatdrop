# NeatDrop v10 主题与组件动效适配

日期：2026-11-07，Asia/Shanghai。基线 `2fbf0df`，分支 `feat/craft-theme-v10`。

## 范围与风格

本轮按用户指定保留内容框架、模板关联、底层链接、布局与信息层级、组件尺寸、对齐和间距、
操作与反馈规则，以及所有现有内容、数据和功能。只调整配色、字体视觉、材质、边界和主题表达。
组件未新增布局包装，也未新增导航、功能按钮或数据字段。

实际浏览的参考：

- [getdesign.md 网站目录](https://getdesign.md/design-md)。查看 Eraser 与 Craft，最终选择
  [Craft](https://getdesign.md/design-md/craft-do) 的暖纸感、柔和表面、克制阴影及清楚文字。
  公开目录可浏览，但该条目的 DESIGN.md 需要单独申请；本轮基于公开页面与图片调研，未声称取得付费分析文件。
- [React Bits Spotlight Card](https://reactbits.dev/components/spotlight-card)：借鉴柔和指针光及边缘反馈。
- [React Bits Specular Button](https://reactbits.dev/components/specular-button)：借鉴按钮细高光、轻按压反馈。
- [React Bits Fade Content](https://reactbits.dev/animations/fade-content)：借鉴短淡入，不采用滚动等待、模糊文字、逐行延迟或长时间显隐。
- 也查看 Border Glow；未加入强烈网格光、持续旋转或彩色发光边界，以保持文件工具的阅读与审核清晰度。

参考方向为暖白纸面、石墨文字、深绿按钮、淡鼠尾草选中态。图谱保留 Graphify 形态与类别颜色，
只将深色画布/面板材质调为协调的石墨绿。字号、行高、字体家族、字距和组件几何沿用原有规则；
调整文字对比及字体抗锯齿，避免字体替换引起换行和布局变化。所有字体使用本机可用字体。

实施前基于现有工作台截图生成一张换肤概念图；最终网页以原有真实内容与几何为准，
不照搬生成图可能出现的文字和尺寸偏差。

## 实施

- `tokens.css` 仅更新色彩、柔光、阴影和曲线令牌，尺寸/间距/字号令牌保持原值。
- 新增 `theme.css` 作为视觉覆盖层。通用控件、空状态、流程步骤、文件表格/卡片、预览、资料库、
  设置、帮助和图谱共用主题规则。无边框宽度或组件宽高变更。
- `useThemeEffects` 用被动指针监听和一帧合并，给现有表面更新两个本地 CSS 变量。没有拦截点击、
  修改 DOM 结构、等待动效后才反馈、后台定时循环或新增网络请求。
- 页面180ms淡入、抽屉160ms短过渡沿用原有时长。按钮反馈只改变高光、颜色和阴影，
  不使用放大或位移改变点击位置。减少动态效果时关闭动画/过渡/指针柔光；触屏使用静态材质。
- 无第三方动效依赖、CDN、在线字体或运行时素材下载。React Bits 是公开交互形式参考，
  本地实现轻量适配，未整体引入其组件包或 GSAP。
