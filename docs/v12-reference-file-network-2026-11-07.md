# NeatDrop v12 黑灰文件网络与曲线

日期：2026-11-07（Asia/Shanghai），基线`df5efe9`，分支`feat/reference-file-network-v12`。

本轮按用户提供的新参考调整知识图谱：白底、明显的黑灰实心圆点、自然散开的文件网络，
文件之间所有连线改为曲线，节点下方不显示任何文字。名称在选中状态条、文件列表和侧边预览中提供。

## 实施

- `graphProjection.ts`：画布只投影文件；移除分类/子分类虚拟中心及其归属边。
  按全库排序生成稳定的黄金角散点，分类变化不决定空间位置，过滤前后种子保持；
  局部保留聚焦和最多20个直接邻居，也使用散点。
- 分类分组、搜索、筛选、每组8项、继续50项、收起操作仍在原侧栏。
  画布上限200个文件节点、完整列表最多1000个文件，隐藏数量仍明确提示。
- `GraphCanvas.tsx`：纯白底、黑#151515/灰#818181圆点，基础直径14px；
  圆点根据三维深度变化尺寸，独立点击区域约24px。文本元素完全移除。
- 全部文件关系使用二次贝塞尔曲线，箭头/虚线/依据交互保留。
  同端点多条关系分配唯一的非零曲率，3/5条混合方向曲线最近中点间距27px，
  大于14px命中线宽，避免前一条关系被后绘制关系吃掉点击。
- 原有3D旋转、拖动节点、Shift平移、缩放聚拢/展开、键盘操作、模式独立相机及位置缓存沿用。
- 没有新增库、CDN、外部字体、网络请求或CSP例外，没有更改全站浅绿主题和图谱外的布局/层级。

连线只来自已存在的归档事实、人工关系和候选，不根据距离、颜色或同类别凭空创建文件关系。
无关联文件仍显示为独立节点，分类信息从右侧筛选和文件列表读取。

## 验证

前端全量：31个测试文件259项通过，11.28秒。TypeScript/Vite生产构建通过。
新增/修订回归覆盖文件专用投影、无虚拟分类关系、分类无关的稳定种子、自然局部分布、
选中也无下方文本、单边曲线及3/5条平行曲线分离。旧的3D、焦点、预览与关系依据测试保留。

真实浏览器1440×1000：24文件节点/21曲线/0直线/0节点文本，可信预览与关系依据读取成功，
筛选位置恢复，三维拖动24节点深度变化、无误开详情。
390×844触屏：纵向滑动滚动页面而不挪动文件，横向拖动旋转网络；无横向溢出、无节点文字。
观察无相关控制台异常，资源只来自本机服务。独立审查发现的奇数平行曲线问题已修复并复核通过。
