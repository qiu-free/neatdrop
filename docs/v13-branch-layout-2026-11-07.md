# NeatDrop v13 恢复清楚的分支排布

日期：2026-11-07（Asia/Shanghai）。基线`a51f499`，分支`fix/graph-branch-layout-v13`。

用户指出上一轮散点排布过于杂乱，要求恢复最开始的分支形态。
本轮保留黑灰圆点、所有曲线、无节点文字、3D拖动和缩放，仅重新组织默认节点位置。

## 修改

新增`frontend/src/graphLayout.ts`：使用真实文件关系建立无向邻接表，仅用于排布。
各连通组独立展开和打包，组间保留留白。短链沿弧连续排列，环按相邻顺序单向排列，
树根据子分支分配扇区，同层间距不足时扩大半径；高连接度分层，极深分支使用有界蛇形后备。

`graphProjection.ts`导出新布局，投影的文件、关系、筛选、搜索、展开数量和容量上限保持。
`GraphCanvas.tsx`删除新节点单独乘1.7的横向变换，将布局、保存坐标和碰撞检查统一为世界坐标。
旧节点精确保留拖动位置；展开新节点时靠近其现有分支并避让，过滤往返和模式独立相机沿用。

不增加分类虚拟节点，不生成新关系，不删改归档事实、候选或人工关系。
不修改后端、分类准确率、索引存储和可信副本读取边界。

## 测试与验收

- 前端全量：32个文件269项通过，15.15秒。
- TypeScript/Vite：通过；画布组件约15.69kB、gzip6.15kB，无新依赖。
- 布局回归：分量留白、短链无交叉、稳定排序、保存位置、200节点性能、4/6/12/200环、
  200节点星图、145节点宽树、200节点长T形分支和真实画布增量展开均通过。
- 独立审查：原环交叉、宽树重叠、深树溢出、缓存坐标二次缩放四项均定向复验通过。
- 浏览器同一24文件/21关系样例：默认视角四组短分支，曲线采样检测非共享端点交叉对数0；
  0节点文字，预览/焦点恢复/搜索往返正常。
- 缩放时分支继续聚拢或展开；桌面鼠标和手机横向触摸均产生24节点深度变化。
- 390×844手机无横向溢出，纵向滑动正常滚动且不挪动节点；观察无相关控制台异常。

本轮仅更改前端，未重复运行后端全量。验证使用已有合成资料，没有执行新的复制或更改原件。
默认排布尽量减少交叉；复杂网络的非树关系和自由旋转仍可能产生投影交叉，所有真实边继续保留。
