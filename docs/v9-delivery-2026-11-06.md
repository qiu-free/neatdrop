## 用户可见行为

归档后从导航进入“知识图谱”，查看分类分组、文件节点和跨文件连线。
图谱形态参考官方 [Graphify](https://github.com/Graphify-Labs/graphify) 的
[网络示例](https://raw.githubusercontent.com/Graphify-Labs/graphify/v8/docs/graph-hero.png)：
深色关系画布、分类配色的圆形节点、自然聚类网络及右侧分组数量。
本项目保留自己的本机处理与可信读取流程；分类分组来自归档类别，没有宣称自动发现语义社区。

全局图谱用于概览，“局部关系”用于查看一份文件及其直接邻居。文件节点和列表都能打开
可信预览，资料库和图谱可定位同一归档副本。关系分为归档时重复内容、本机相似候选和
人工确认关系。自动候选保持待确认，可查看双方依据，再确认、忽略或手动补充方向明确的关系。

“分析关联”主动选择副本并同意本机保存衍生特征后才开始。进度支持取消，取消不发布未完成批次。
索引管理可清除特征及自动候选，正常清除保留人工关系和文件。刷新或重启后重新授权同一目录
可恢复索引及人工关系。撤回的副本与关系从图谱隐藏，原件及已有分类路径不变。

图谱的使用步骤与边界也已纳入 [日常使用指南](daily-use.md)；应用内“使用说明”可搜索
知识图谱、Graphify、关系和索引。

## 离线处理与可信边界

- 文本：NFKC 归一化、英文词项/中文片段、模板与通用词过滤、稀疏 TF-IDF/余弦排序。
  需要至少两项独立且不重叠的共同正文线索。低质量文字不能支持文本相似候选。
- 图片：使用方向校正后的感知差异指纹。图片 OCR 可以参与文本匹配；图谱索引不运行 CLIP，
  不依赖语义模型或向量数据库。视觉候选不能推断主题、人物、地点、事件。
- 所有内容读取接受归档 ID，验证当前目录授权、本机可信凭据、文件身份、大小和 SHA-256。
  预览、关系证据与候选确认均核验当前字节。旧索引只是历史快照。
- 本地状态采用版本与修订控制、有界结构校验、受保护目录和原子写入。
  `.neatdrop-state/knowledge-graph/` 保存有限关键词、位置、摘要、指纹和人工关系；不持久化全文、
  原始 OCR 或图片，不纳入 Git。损坏快照的重建不能恢复其中已损坏的人工关系元数据。
- 代码及画布库随本机生产构建交付，无 CDN、Graphify 云端、遥测或运行时模型下载。

## 关联质量验收

冻结合成验收集 `scripts/evaluation/graph_corpus_v9.json` 包含40组相关、40组易混淆无关对，
共160文件、80个不同主题；中文、英文、表格风格及 OCR 风格文本混合。语料在最终匹配前冻结，
SHA-256：`9e74605e5559b6bb1ec2b4b15c6b333924143e75fbc5bca00795212562024825`。

| 指标 | 实测 |
| --- | --- |
| 自动候选 | 40条，40条与标注一致 |
| 候选精度 | 100%（40/40，仅此合成文本集） |
| 相关文件至少一条正确关联 | 100%（80/80，仅此合成文本集） |
| 无结果文件 | 80，全部来自无关样本 |
| 质量受限文件 | 0，此集合提供可读文字 |
| 1000条特征匹配 | 2496条候选，单端最多5条，0.9384秒 |

另外使用真实 DOCX/PPTX/XLSX/CSV 字节经过实际提取再匹配，及实际压缩图片字节的指纹候选检查。
中文同主题召回和通用流程模板反例在接受审查后补充回归。

这些样本共享主题线索较明确，不能推断用户真实资料的准确率。OCR 风格文本由人工提供，
不等于 OCR 引擎质量测试；真实图片检查也只覆盖相近压缩图，不代表图片语义理解能力。
1000条测试只计纯匹配，不包含解析、OCR 或画布。候选提名有上限，密集大集合可能漏掉关系。

## 使用边界

每批最多50个副本、单个20MiB、合计200MiB，最多12000字符采样；最近1000份归档记录，
画布最多200节点，局部最多20邻居。单目录1000个索引、5000条人工关系，每文件256个词项、
每词3个位置，快照16MiB、关系元数据2MiB。多独立后端进程并行写同一安装状态不受支持。

扫描版 PDF OCR、旧 Office、宏/加密/危险嵌入容器、照片语义识别等继续遵守原版本限制。
本次重点是离线关系浏览与可核对候选，不是新的分类准确率承诺。
